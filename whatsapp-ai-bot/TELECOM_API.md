# توثيق خدمات الاتصالات

## الإعدادات

```env
STAR_API_TOKEN=your-api-token
```

Base URL:

```text
https://star26.vercel.app/api/external/v1
```

كل الطلبات تستخدم:

```http
Authorization: Bearer STAR_API_TOKEN
Accept: application/json
Content-Type: application/json
```

## الاستعلام

```http
GET /query?service=yem&action=query&mobile=777123456
```

الخدمات المدعومة:

| service | الشركة | actions |
| --- | --- | --- |
| `yem` | يمن موبايل | `query`, `solfa`, `queryoffer`, `bill`, `billoffer` |
| `you` | YOU | `query`, `queryoffer`, `bill`, `billoffer` |
| `yem4g` | يمن فورجي | `query`, `bill` |
| `post` | الهاتف الثابت والإنترنت | `query`, `bill` |
| `adenet` | عدن نت | `query`, `bill` |

لخدمة `post` يجب تمرير `type=adsl` أو `type=line`.

يتحقق البوت من رقم الخدمة حسب الشركة: يمن موبايل يبدأ بـ `77`، وYOU يبدأ بـ `73`، ويمن فورجي يبدأ بـ `10`، بينما الهاتف الثابت والإنترنت وعدن نت تبدأ أرقامها بـ `0`.

## السداد

```http
POST /pay
Content-Type: application/json
Authorization: Bearer STAR_API_TOKEN
```

```json
{
  "service": "yem",
  "action": "bill",
  "mobile": "777123456",
  "amount": 1000,
  "payerMobile": "770326828"
}
```

في هذه الحالة `mobile` هو الرقم المستفيد من خدمة الاتصالات، و`payerMobile` هو رقم العميل الموثق الذي يخصم منه الرصيد. يجب أن يدعم خادم `/pay` الحقل `payerMobile` عند السداد لرقم مختلف. إذا كان الخادم يعتمد على `mobile` وحده، فلا يمكن ضمان خصم رصيد الدافع عند دفع رقم آخر، ويجب تحديث الخادم أولاً.

## حماية الخصم

لا يأخذ البوت رقم العميل من الرسالة أثناء تنفيذ العملية. قبل السداد:

1. يجب أن يكون حساب Telegram مربوطًا عبر OTP.
2. يستخرج البوت الرقم المحفوظ المرتبط بـ `telegram_id`.
3. يتحقق من أن الرقم يبدأ بـ `7` ويتكون من 9 أرقام.
4. يرسل رقم الخدمة في `mobile` ورقم العميل الموثق في `payerMobile` إلى `/pay`.
5. إذا لم تتطابق الهوية أو لم يوجد الربط، لا يتم إرسال طلب الدفع.

بذلك يعرف الخادم رقم الخدمة المستفيد ورقم الدافع بشكل منفصل، ولا يعتمد البوت على Telegram ID كبديل عن رقم الحساب.

## تدفق البوت

من القائمة الرئيسية:

1. اختر `خدمات الاتصالات`.
2. اختر الشركة.
3. اختر `استعلام` أو `سداد`.
4. الاستعلام يطلب رقم الخدمة المراد الاستعلام عنه، ويمكن أن يكون مختلفًا عن رقم الربط.
5. يمن موبايل يعرض الرصيد والسلفة والباقات في استعلام شامل واحد.
6. السداد يطلب رقم الخدمة ثم المبلغ، ويرسل `mobile` للهدف و`payerMobile` للعميل الموثق.
7. تظهر نتيجة API للعميل، ولا يعرض البوت نجاحًا إذا رفض النظام العملية.
